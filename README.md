# study

Minimal Node.js audiobook player: import audio from YouTube playlists, play
them grouped as "books", resume where you left off. Installable as a PWA
with a compact widget mode.

## Requirements

- Node 18+ (no npm dependencies — pure Node)
- `ffmpeg` on PATH — audio conversion (and `ffprobe` for the optional chapter API)
- `yt-dlp` for YouTube import. Looked for at `$YT_DLP`, `~/.local/bin/yt-dlp`,
  `/usr/local/bin/yt-dlp`, `/usr/bin/yt-dlp`, then `yt-dlp` on PATH.
  ```bash
  curl -L -o ~/.local/bin/yt-dlp https://github.com/yt-dlp/yt-dlp/releases/latest/download/yt-dlp_linux
  chmod +x ~/.local/bin/yt-dlp
  ```
  yt-dlp needs a JS runtime to extract from YouTube; import passes
  `--js-runtimes node` (override with `YT_DLP_JS_RUNTIME`), plus a socket timeout
  and 2–5s inter-video sleep.
- **Cookies (optional):** if YouTube demands "confirm you're not a bot", drop a
  Netscape-format `cookies.txt` in the project root (or `~/.config/yt-dlp/cookies.txt`,
  or point `YT_DLP_COOKIES` at one) and import will pass `--cookies`.

## Run

```bash
npm start          # → http://localhost:8250  (set PORT to change)
```

## Tests

```bash
npm test           # fast HTTP/API tests (node:test, no browser)
npm run test:browser   # Playwright regression tests for the player UI
npm run test:all       # both
```

`test:browser` needs a Chromium: `npx playwright install chromium` (it auto-skips
if none is found). It covers the play/pause button, spacebar toggle, next/prev,
resume-on-reload, widget mode, the chapter review quiz (heads-up note,
open-on-finish, per-question feedback, scoring, retakes), and the type
hierarchy + music-only shuffle. `npm test` also validates every
`data/quizzes/*.json` for shape and that no quiz points at a chapter with no
audio track, the `guessType` import heuristic, and `.type` marker resolution
in `/api/files`.

## Chapter review quizzes

Drop a `data/quizzes/NN.json` file per chapter (`NN` = the track's 1-based
position in its book). Shape:

```json
{
  "chapter": 1,
  "title": "Book One, Chapter 1 — review",
  "questions": [
    { "q": "…?", "choices": ["a", "b", "c", "d"], "answer": 2, "explain": "…" }
  ]
}
```

Exactly 10 questions, 4 distinct choices each, `answer` is the 0-based index.
While a chapter with a quiz plays, the player shows a heads-up note; the quiz
opens automatically when the audio finishes (and can be taken again any time
from the **Take the review quiz** button). Each answer is marked right/wrong
immediately with its explanation. Scores persist per track in `localStorage`
and show as a badge in the sidebar. The `data/` directory is a bind-mount in
`docker-compose.yml`, so quizzes can be added without rebuilding the image.

## Import a playlist

**From the UI:** paste a YouTube playlist (or single video) URL into the box in
the sidebar, optionally name the folder, click **Import audio**. The app looks
up the playlist (no download yet) and suggests a library type — **Book**,
**Music**, or **Other** — guessed from the title/uploader text and the average
track length (a few long tracks reads as a book; many short ones reads as an
album); confirm or override it, then **Start import**. Progress streams live.
Each video becomes `audio/<playlist title>/NN - <video title>.mp3` with
metadata and cover art embedded, plus a `.type` marker file recording the
confirmed type.

**From the CLI:**
```bash
node import.js "https://www.youtube.com/playlist?list=..." --name "My Book" --type book
```

## Playing

- The sidebar is grouped **Type → playlist → track** (Books / Music / Other —
  a section only appears if it has anything in it). One folder under `audio/`
  = one playlist; its type comes from the `.type` marker the importer wrote
  (missing marker = "book", so anything dropped straight into `audio/`
  without going through import still shows up as before).
- Click a track to play; playback auto-advances to the next track in that
  playlist (toggle off with **Auto-advance**), and ⏮/⏭ move between tracks.
- **Shuffle** (🔀) appears in the transport only while playing something typed
  as **Music** — it randomizes ⏮/⏭/auto-advance order within that playlist.
  The choice is remembered per browser.
- Your position in every track is saved in the browser (`localStorage`) and
  restored on reload. Finished tracks show ✓; partial ones show a percentage.

## Chapters (optional)

With playlists imported from YouTube, each video is already its own track, so the
chapter UI is disabled. The silence-detection API is still available:
`GET /api/chapters?file=<path>&noise=-30&minSilence=0.5&gap=1.5`.

## Install as an app (Chrome / Chromebook)

The app is a PWA (`manifest.webmanifest` + `sw.js`, icons generated by
`node tools/gen-icons.mjs`). Over HTTPS (study.mooseflip.com) Chrome shows an
install button in the address bar — or use the **Install** button in the app
header. Once installed it opens in its own resizable, movable window.

- **Float on top of other apps:** on ChromeOS, right-click the app window's title
  bar → **Always on top**.
- **Widget mode:** the **▁** button in the player collapses the app to a compact
  transport bar (title + ⏮ ⏯ ⏭ + seek); in an installed window it also shrinks
  the OS window to ~400×132 and restores the previous size when expanded. The
  choice is remembered. OS media keys / the ChromeOS media tray also control
  playback (via the Media Session API).

## Deployment

Runs at **https://study.mooseflip.com** via the mooseflip Cloudflare Tunnel
(ingress `study.mooseflip.com → http://localhost:8250`, managed through the
Cloudflare API). Start with `PORT=8250 npm start` (8250 is the default).

## API

| Endpoint | Purpose |
|---|---|
| `GET /api/files` | all audio files (with subfolder paths) + `folderTypes` (playlist path → book/music/other) |
| `GET /audio/<path>` | range-enabled audio stream |
| `GET /api/chapters?file=<path>&noise=-30&minSilence=0.5&gap=1.5&force=1` | chapter detection |
| `GET /api/import/inspect?url=<yt-url>` | no-download lookup: folder name, suggested type, track count |
| `GET /api/import?url=<yt-url>&name=<folder>&type=<book\|music\|other>` | SSE stream of import progress |
| `GET /api/quiz?n=<chapter>` | chapter review quiz JSON (404 if none) |
| `GET /api/yt-dlp` | resolved yt-dlp path |
